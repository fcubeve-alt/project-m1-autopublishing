# 接入指南 — 给外部项目

**读完本文即可完成 L1 接入，无需了解 Money OS 内部。**

## 先确认：你可能什么都不用做

| 级别 | 你要做的 | 你得到的 |
|---|---|---|
| **L0** | **无。** 告知 Money OS 你的项目名即可 | 出现在组合视图 |
| **L1** | **两个本地文件** | 财务汇总、组合指标、Supervisor 建议 |
| **L2** | 再加四类记录 | 完整治理 |

**永久停在 L0 或 L1 是完全正常的终态。** 没人会催你升级。

## L1：两个文件

在你的项目里建一个目录（名字随意，惯例是 `.moneyos/`）：

**`project.json`** — 一次性写好，之后基本不动：

```json
{
  "contract_version": "0.1",
  "project_id": "your-project",
  "name": "Your Project",
  "integration_level": "L1",
  "status": "ACTIVE",
  "base_currency": "USD",
  "recorded_at": "2026-08-16T00:00:00Z"
}
```

**`ledger.ndjson`** — 每行一条收支。**允许按月聚合**，不必逐笔：

```json
{"id":"2026-07","direction":"REVENUE","date":"2026-07-31","category":"subscriptions","net_usd":1234.50,"cash_received_usd":1100.00,"human_minutes":null,"recorded_at":"2026-08-01T00:00:00Z"}
```

**完成。** 没有 SDK、没有网络调用、没有注册流程。

## 五条你可以依赖的保证

1. **Money OS 永不写入你的系统。** 只读。
2. **Money OS 停机不影响你。** 你写本地文件，它自己去读。
3. **不要求你改业务代码。** 导出脚本属于你，几十行，随时可删。
4. **不认识的字段会被忽略。** 你可以自由加字段。
5. **删掉那个目录就完全脱离。** 业务系统零改动。

## 常见问题

**必须用 Git 吗？**
不必。Git 不是架构依赖，只是可选传输之一。文件系统、REST、队列、数据库同步、
CLI、甚至手工上传都可以，**且更换传输不需要你改任何东西**。

**必须用 Python / 装这个包吗？**
不必。契约是文件格式。用任何语言生成，或手写，都合规。

**我的业务是高频小额交易，要逐笔上报吗？**
不要。按日/周/月聚合成一行即可，在 `category` 注明口径。

**`human_minutes` 我填不出来。**
留 `null`。它对全自动业务本就不适用——这一条正是被第二个业务改出来的。

**我不想让 Money OS 看到某些数据。**
就别导出。你只导出你愿意共享的。契约不要求完整性。
