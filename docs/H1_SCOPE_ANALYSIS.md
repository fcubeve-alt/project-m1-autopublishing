# H1 阻塞范围分析 — 逐候选，不做整体传播

**日期:** 2026-08-16 · **证据:** `evidence/EVIDENCE_STORE.csv`

**H1 =** Owner 的税务居住国 / KDP 账号 / 可用支付轨（`PROJECT_STATE.md` §7）。

**本文回答一个问题：H1 究竟卡住哪几个实验，哪些不受影响。**
单个平台的 Human Gate **不自动升级为整个 M-A 的 Human Gate**。

---

## 1. 逐候选：卡在哪一环

Gate 分四环：**注册 → 发布 → 参赛/投稿 → 提款**。同一个平台可能只卡其中一环。

| 候选 | 注册 | 发布 | 投稿/参赛 | 提款 | **H1 是否阻塞** |
|---|---|---|---|---|---|
| **Listverse** | 无需账号 | — | ⛔ **仅限 7 国新投稿人** `EV-020` **[S]** | ✅ PayPal/Bitcoin，无起付线 `EV-019` **[P]** | 🔴 **是 —— 卡在投稿准入** |
| **Vocal** | ✅ 全球可注册 `EV-003` **[P]** | ⛔ **须连接 Stripe 并完成 KYC 才能发布** `EV-004` **[P]** | 参赛本身不限国 | ⛔ Stripe 独家，约 46–47 国 `EV-005` **[P]** | 🔴 **是 —— 卡在发布，本轮升级** |
| **Pratilipi** | 无已知限制 | 无已知限制 | — | 🟡 INR 结算，门槛 `UNKNOWN` `EV-028` **[S]** | 🟢 **否 —— 无已知国别封锁** |

## 2. 本轮的关键变化：Vocal 的阻塞点上移了

我上一轮写过「Vocal 参赛与获奖不受限，只有提款受限」，据此认为 Vocal 实验可以先跑起来、
把钱挂在钱包里。**这个判断已被官方公告推翻。**

Vocal 的 "Verified Publishing" 改版明确：

> **创作者必须连接 Stripe 并完成身份验证（KYC）才能发布。**

因此 `EV-006`（不支持国家的收入可挂账）对**新账号不再是可行路径**，已标 `WITHDRAWN`。
**Vocal 现在从第一步就需要 Stripe 可用的国家**，H1 从"提款门槛"升级为"入场门槛"。

同一份公告还改变了 Vocal 的经济性：

> **阅读收益now为 Vocal+ 会员独占（$9.99/月）；免费账号发布的故事不再通过阅读赚钱。** `EV-036`

⚠️ **这里有一个必须讲清楚的微妙点：** 被 A-001 撤回的那句「Vocal 阅读收益仅限 Vocal+」
**现在在事实层面成真了**——但它是在被撤回**之后**因平台改版才成真的。
**A-001 的撤回依然正确**：该说法在当时没有证据支持（同一单元格里并列记着 $3.80 标准档费率）。
**结论正确不等于推理成立**，这条不能拿来反证审计做错了。

## 3. 结论：H1 阻塞两个，不阻塞第三个

| | |
|---|---|
| 🔴 **被 H1 阻塞** | **Listverse**（投稿准入 7 国）· **Vocal**（发布须 Stripe KYC） |
| 🟢 **不被 H1 阻塞** | **Pratilipi** —— 无已知国别封锁 |

**因此不向 Owner 提出 H1。** 按既定原则：只要还有一个高排名实验可以在 H1 未知的情况下推进，
就先推进它，H1 只挂在真正受影响的候选上。

**H1 现在的正确表述**（取代我上一轮"H1 重回关键路径"的过强说法）：

> H1 阻塞 Listverse 与 Vocal 这两条路径。它**不阻塞 M-A**，也不阻塞 Pratilipi。
> 一旦 Owner 主动提供国别，上述两条即可立刻重估——但项目不为此停等。

## 4. Pratilipi 的真实阻塞项不是 H1

Pratilipi 的阻塞是 **`EV-038` / `EV-027`：AI 政策与非印度作者可用性 `UNKNOWN`**。

**这不是 Human Gate——是搜索可解的缺口。** 且按 R1，`UNKNOWN` 不得作为淘汰依据，
它只决定"能否立即发布"，不决定"是否值得投入"。

**下一步（无需 Owner）：** 前两次按域名限定搜索未找到 AI 条款，第三次改换角度——查其
服务条款正文与非印度作者的使用报告。若查明允许或未禁止，Pratilipi 即成为首个可实际启动的
Class A 实验。
